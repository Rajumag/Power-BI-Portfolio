# Power BI Portfolio

## Welcome to my Power BI Projects Portfolio
This repository showcases a collection of 20 end-to-end Power BI dashboards that I built using real-world datasets. Each project is a complete workflow, from data procurement to visualization, demonstrating practical applications in data analysis.

## Each project demonstrates my ability in:
✔️ Data Procurement (Sourcing datasets from APIs, CSV files, databases, or web scraping where applicable)  
✔️ Data Cleaning & Transformation (Using Power Query for handling missing values, duplicates, formatting, and ETL processes)  
✔️ Data Integration (Merging multiple data sources for comprehensive analysis)  
✔️ Data Modeling (Implementing Star Schema, managing relationships, and optimizing for performance)  
✔️ Advanced DAX Measures & Calculations (Creating custom metrics, time intelligence functions, and dynamic calculations)  
✔️ Parameters & Dynamic Filtering (Adding Power Query parameters for flexible data folder updates and DAX parameters as slicers/filters for quick, interactive insights)  
✔️ Interactive & User-Friendly Dashboard Design (Building beautiful, responsive visuals with storytelling elements like tooltips, bookmarks, and drill-throughs)  
✔️ Storytelling with Data (Highlighting key insights, trends, and actionable recommendations)

## The dashboards cover a variety of industries such as Finance, Sales, HR, Marketing, Healthcare, Supply Chain, Sports, Education, and more.

# 📂 Projects List

## 🌍 Environment & Health
- **AQI Index and Weather Report**: Procured air quality and weather data from public APIs and datasets; cleaned and transformed using Power Query to handle inconsistencies in pollutant levels, humidity, and wind data; integrated multiple sources for a unified view; modeled with star schema focusing on time and location dimensions; created DAX measures for AQI trends, averages, and forecasts; added parameters for date ranges and pollutant filters; designed a beautiful dashboard with maps, gauges, and line charts for real-time monitoring.  
- **Patient Data Analytics**: Sourced patient records from healthcare datasets; performed data cleaning in Power Query for anonymization and error correction; integrated admission, treatment, and outcome data; built a relational model with patient and hospital dimensions; developed DAX measures for readmission rates, average stay, and outcome predictions; included dynamic parameters for filtering by demographics or conditions; created an interactive dashboard with KPI cards, bar charts, and slicers for clinical insights.  

## 💼 Business & Finance
- **ATM Data Dive**: Gathered transaction data from banking logs; cleaned and transformed in Power Query to resolve timestamp issues and outliers; integrated with location and user data; modeled using star schema for transaction facts and account dimensions; crafted DAX measures for withdrawal patterns, peak hours, and fraud indicators; added Power Query parameters for data folder updates and DAX filters for transaction types; built a visually appealing dashboard with heatmaps and trend lines for operational efficiency.  
- **Anomaly Detection Report**: Procured anomaly datasets from various business sources; used Power Query for cleaning anomalies and normalizing data; integrated time-series data; designed a model with anomaly detection dimensions; created advanced DAX for z-scores, thresholds, and alerts; incorporated parameters for sensitivity adjustments; developed a dashboard with scatter plots and alerts for quick detection.  
- **Procurement Spend Analysis**: Sourced spend data from procurement databases; cleaned for duplicates and categorization in Power Query; integrated supplier and category data; modeled with spend facts and vendor relationships; built DAX measures for cost savings, vendor performance, and trends; added filters via parameters for categories and periods; designed an elegant dashboard with pie charts and tables for spend optimization.  

## 🧑‍🤝‍🧑 HR & Workforce
- **Employee Churn Analysis**: Obtained HR datasets from employee records; transformed and cleaned in Power Query for handling attrition factors; integrated performance and demographic data; modeled with star schema for employee facts; developed DAX for churn rates, retention metrics, and predictive scores; used parameters for department and tenure filters; created a user-friendly dashboard with funnels and gauges for HR strategies.  
- **HR Analysis**: Procured workforce data from HR systems; cleaned for inconsistencies in Power Query; integrated payroll and performance sources; built relational models; crafted DAX measures for diversity ratios, salary benchmarks, and absenteeism; added dynamic parameters for role-based filtering; designed an interactive dashboard with cards and bar charts for talent management.  
- **Student Performance Analysis**: Sourced educational datasets; used Power Query for cleaning grades and attendance; integrated course and student data; modeled with performance facts; created DAX for average scores, dropout risks, and trends; included parameters for subject and grade filters; built a visually engaging dashboard with line charts and slicers for academic insights.  

## 📈 Marketing & Sales
- **Digital Campaign Effectiveness**: Gathered campaign data from marketing platforms; cleaned impressions and clicks in Power Query; integrated channel and engagement sources; modeled with campaign facts; developed DAX for ROI, conversion rates, and attribution; added parameters for campaign type filters; designed a beautiful dashboard with funnel visuals and KPIs for optimization.  
- **E-Commerce Amazon Clothing Sales Report**: Procured sales data from e-commerce APIs; transformed in Power Query for product categorization; integrated customer and inventory data; built star schema models; created DAX measures for sales trends, basket size, and forecasts; used Power Query parameters for data updates and DAX slicers for categories; crafted an interactive dashboard with maps and charts for revenue growth.  
- **Sales Analysis and Trends**: Sourced sales datasets; cleaned for regional variations in Power Query; integrated product and customer data; modeled relationships; built DAX for year-over-year growth and top performers; added filters via parameters; developed a sleek dashboard with trend lines and heatmaps for sales strategies.  
- **Social Media Analytics**: Obtained engagement data from social APIs; used Power Query for cleaning metrics; integrated platform sources; modeled with engagement facts; created DAX for sentiment scores, reach, and virality; incorporated parameters for post-type filtering; designed a vibrant dashboard with graphs and word clouds for campaign insights.  

## 🚚 Supply Chain & Operations
- **Call Center Management**: Procured call logs; cleaned durations and resolutions in Power Query; integrated agent and customer data; modeled with call facts; developed DAX for average handle time, satisfaction scores, and queues; added parameters for shift filters; built a dashboard with KPIs and bar charts for efficiency.  
- **Inventory Management**: Sourced inventory datasets; transformed stock levels in Power Query; integrated supplier data; built models for inventory turns; created DAX measures for stockouts and reorder points; used parameters for warehouse filtering; designed an operational dashboard with gauges and tables.  
- **Production Efficiency**: Gathered manufacturing data; cleaned for defects in Power Query; integrated machine and shift sources; modeled production facts; built DAX for OEE, downtime, and yields; added dynamic parameters; created a dashboard with line charts and alerts for improvements.  
- **Vehicle Registrations of Cars**: Procured registration data; used Power Query for cleaning vehicle types; integrated geographic sources; modeled with registration dimensions; developed DAX for trends and compliance rates; included filters for models; designed a dashboard with maps and trends for logistics.  

## 🏨 Hospitality & Entertainment
- **Hotel Industry Report**: Sourced booking data; cleaned cancellations in Power Query; integrated guest and room sources; modeled bookings; created DAX for occupancy rates and revenue per room; added parameters for season filters; built an elegant dashboard with calendars and charts.  
- **Movie Recommendation System**: Obtained movie datasets; transformed ratings in Power Query; integrated genre and user data; built recommendation models; developed DAX for similarity scores and top picks; used parameters for genre slicers; designed an interactive dashboard with matrices and visuals for personalized suggestions.  

## ⚽ Sports & Analytics
- **Olympic Game Gaze Analytics**: Procured Olympic data; cleaned medal counts in Power Query; integrated athlete and event sources; modeled with performance dimensions; created DAX for rankings and historical trends; added filters for countries; crafted a dashboard with medals tables and charts for insights.  
- **World Cup Data Analysis**: Sourced match data; used Power Query for cleaning scores; integrated team and player stats; built models for game outcomes; developed DAX for goal averages and predictions; included parameters for tournaments; designed a dynamic dashboard with heatmaps and brackets for fan analysis.
